# SearchDemonSlayerAPI

Aplicação simples desenvolvida em C# com .NET 10 e Blazor WebAssembly para consumir a API de Demon Slayer.

## Funcionalidades

- Listar personagens.
- Buscar personagens pelo nome.
- Navegar entre as páginas da API.
- Exibir nome, idade, raça, citação e imagem.

## Tecnologias

- .NET 10
- C#
- Blazor WebAssembly
- HttpClient
- Demon Slayer API

## Como executar

É necessário ter o SDK do .NET 10 instalado.

No terminal, dentro da pasta do projeto:

```bash
dotnet restore
dotnet run
```

Acesse o endereço informado pelo terminal.

## API

Documentação: https://www.demonslayer-api.com/documentation

Endpoint: https://www.demonslayer-api.com/api/v1/characters?page=1
